# Альпачино – игра

Игра на одну песню: ограбление банка длиной ровно в трек «Альпачино» группы «чартер».
Музыка играет, пока ты жив.

**Играть: [alpachino-game.ru](https://www.alpachino-game.ru/)**

## Что в репозитории

Только опубликованная копия. Исходники и сборщики живут не здесь, а у автора
на диске, поэтому править файлы прямо в репозитории не нужно – при следующей
выкладке правка затрется.

| Файл | Что это |
|---|---|
| `index.html` | вся игра: разметка, стили, код и шрифт в одном файле |
| `alpachino.mp3` | песня, под которую идет игра |
| `og-1200x630.png` | картинка для карточки ссылки в мессенджерах |
| `favicon-32.png`, `apple-touch-icon.png` | иконки сайта |
| `privacy.html` | что сайт собирает и как это убрать |
| `CNAME` | домен для GitHub Pages |

## Как обновляется

Скриптом `deploy_site.py` из папки с исходниками: он переносит сюда свежие файлы,
коммитит и пушит. Pages пересобирает сайт сам, обычно за минуту.

Отдельно от сайта собирается версия для каталога Яндекс Игр – у нее свои требования
(никаких внешних ссылок), и делает ее `build_yandex.py` из того же `index.html`.
